01

本地 AI：可行，但不适合默认方案

用 FunASR 与 Qwen3-0.6B 完成本地链路验证。CPU 短文本润色约 7.1 秒，确认当前硬件门槛与延迟不满足产品预期。

02

BLE：目标链路余量不足

16kHz / 16-bit / mono 原始音频约 32KB/s。实测暴露队列堆积、丢包与乱序风险，最终保留 USB / WiFi 作为主路径。
